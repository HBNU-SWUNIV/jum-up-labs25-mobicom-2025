## Project Background
디지털 플랫폼 확산으로 정보가 과잉 생산·유통되면서 뉴스 소비자의 비판적 사고와 문해력이 사회 이해의 핵심 역량으로 부상하고 있다. 그러나 최근 20대의 인터넷 뉴스 이용률이 감소하고, 한국 성인의 문해력 점수가 OECD 평균보다 낮아 균형 잡힌 뉴스 이해가 어려운 구조적 문제가 드러난다. 기존 뉴스 서비스는 이용자 수준을 고려하지 않아 복잡한 사회 이슈를 단편적으로만 인식하게 만드는 한계를 가진다. 이에 본 연구는 사용자 문해력 수준에 맞춰 뉴스를 요약·제공하는 맞춤형 플랫폼 **“News Fit”** 을 제안하여, 정보 과잉 시대에 비판적 사고를 촉진하고 사회적 갈등 완화 가능성을 모색한다.

## System Model
![아키텍쳐](./004%20images//architecture.png)
본 플랫폼은 빅카인즈 뉴스 데이터를 GPT-4o로 처리·검수하여 데이터베이스에 저장하며, Spring Boot 기반 백엔드 API 서버와 React 기반 사용자 인터페이스로 구성된다. 또한 Cloudflare를 통해 배포 및 운영이 이루어진다.

## Conclusion
본 연구는 대규모 언어 모델을 활용하여 사용자 어휘력 수준에 맞춘 한국어 뉴스 요약 플랫폼을 설계·구현하였다. 제안된 시스템은 맞춤형 요약, 긍·부정 코멘트, 단어 해설 기능을 통해 이용자의 문해력 향상과 중립적 가치관 형성에 기여할 가능성을 보여준다. 향후 연구에서는 실제 사용자 실험을 통한 효과 검증, 대규모 뉴스 데이터셋 확장, 교육 분야 응용성 평가를 통해 시스템의 실효성과 확장성을 강화할 예정이다.

- 2025 한국통신학회 제 6회 한국 인공지능 학술대회, 인공지능 기반 외국인 노동자 근로 계약서 번역 및 법률 정보 제공 앱
- 2025 한국통신학회 추계종합학술발표회, 대규모 언어 모델을 활용한 어휘력 맞춤형 뉴스 요약 플랫폼 개발
